# Study Buddy Bot

Discord bot for our CS study group server.

## Setup

```
pip install -r requirements.txt
echo DISCORD_TOKEN=... > .env
python bot.py
```

## Commands

- `!ping`, `!roll [sides]`, `!8ball <question>`
- `!deadline <course> <yyyy-mm-dd> <what>` / `!deadlines` / `!done <course> <what>`
- `!pomodoro [minutes]`
